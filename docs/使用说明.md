# NOTE4C 使用说明（v6.6.1）

四色墨水屏（400×300，黑白红黄）。三个按键：**上、下、BOOT**。

## 烧录

用完整 mergebin 刷到 `0x0`，例如：

```bash
esptool.py --chip esp32s3 -b 460800 write-flash 0x0 notellm-2bp-v6.6.1-2bp-8907e59-20261113-mergebin.bin
```

刷完后重新上电。

## 按键

| 操作 | 作用 |
| --- | --- |
| 上 / 下 短按 | 翻页、换选项 |
| 上 连按两下 | 打开页面切换（相册 / 天气 / 日历 / 设置），BOOT 进入 |
| 下 长按 | 进入设置 |
| 上 长按 | 天气、日历、设置页回到相册 |
| 上 + 下 同时长按 | 配网 |
| BOOT 短按 | 确认 / 看大图 / 播报天气 / 看当日黄历 |
| BOOT 长按 | 相册页开热点传图；传图或配网时退出 |

深睡后只有 **BOOT** 能手动唤醒。

## 配网

1. 上 + 下 同时长按，连设备热点 `ZecTrix-xxxx`（无密码）。
2. 浏览器打开 `http://192.168.4.1`，填家里的 Wi-Fi。
3. 配好后长按 BOOT 退出。

设置里可开关 Wi-Fi 和局域网服务。连上 Wi-Fi 后会自动开局域网网页，IP 看设置页。

## 相册和传图

- 相册：上/下换图，BOOT 在列表和大图之间切换。
- 相册长按 BOOT：开热点 `InkScreen-AP`，密码 `12345678`，手机打开 `http://192.168.4.1` 传图。
- 已连 Wi-Fi 时，也可直接打开设置里的局域网 IP。
- 网页可选 1BP 黑白或 2BP 四色。
- 轮播：关闭 / 5 / 10 / 30 分钟。关掉后大图会停在当前这张。

## 天气和日历

- 天气页 BOOT 播报；连按两下 BOOT 立刻刷新。
- 设置可改：每日播报时间（默认 07:00，可关）、进入天气页是否自动播报、白天/夜间更新间隔。
- 白天是 06:00–18:00。夜间更新设为关闭时，18:00 之后不再整点醒来，会睡到早上 06:00。
- 日历：上/下换月，BOOT 看当天；设备大约每 2 小时自动刷新一次日期。

## 省电

无操作约 **5 分钟** 会自动深睡（墨水画面保留）。例外：

- 正在配网或热点传图
- 相册开着轮播

也可在设置里选「省电模式」，或网页点「关闭并省电」。

唤醒：

- 任意页面：按 BOOT
- 天气页：到点自动更新 / 播报
- 日历页：到点自动刷新日期

想尽量省电：相册关掉轮播，停在要展示的大图上，再进省电。
