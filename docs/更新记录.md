# 更新记录

本文整理 zack（shiqizhenyes@gmail.com）在分支 `2bp-community` 上、相对基线 `8907e59` 的 28 个提交，时间从 2026-11-14 到 2026-11-20。按键和日常用法见 [使用说明](使用说明.md)，这里记录这批改动本身。

## 天气与离线语音

天气页从和风天气拉取实况、7 日和指数，用 JWT 鉴权，并在四色屏上画出预报。播报改用片上中文语音。（`ef7b8c2`）

随后在小乐之外增加 LingTTS 的女声 A。深睡唤醒后，设置页回到睡前打开的那一行。（`8f97e4f`）

唤醒后的刷新会先等 Wi-Fi；更新间隔关闭时跳过拉取。画面和播报只使用新鲜缓存。面板刷新期间到来的设置点击会留到刷新结束再处理。快切快照按 2bpp 帧缓冲尺寸截取。固件版本记到 6.6.2。（`4df1794`）

语音最后收成一条：播报使用小林。设置页和局域网页只保留这一条声线，已经保存的「女声 A」仍然选中它。（`9e775dc`）

小乐占用的 `voice_data` 分区随之取消，LingTTS 模型前移，空出来的空间还给相册。（`245fbd2`）

## 日历

日历页移植 InkSight，离线带节日、节气和黄历，并带上云纹和「吉」装饰图。（`bd1cb3d`）

界面改用点阵字之后，月历按新字体重画：顶栏是周一到周日，公历和农历行外套红色的「今天」标记，日签在月历下方的横条里居中。（`d86d044`）

## 省电、时钟与刷新

深睡前把墨水屏信号拉低再断供电，去掉睡眠时漏电的上拉，深睡唤醒后跳过开机白屏刷新，并打开 ESP32 电源管理定时器。（`f9a9e94`）

PCF8563 在深睡期间保持 UTC 时间，并用它记录 RC 定时器的漂移。缺少这颗芯片时继续启动。（`de096c8`）

这些页面、定时唤醒和深睡收尾接到 4.2 寸板子上：空闲可以睡，天气和日历仍按点刷新。（`70b40ee`）

设置页和快切弹层改用黑/黄波形，选中项和进度用黑与黄绘制，这两类画面刷新更快。（`d0dc73c`）

黑/黄遮罩在深睡前保存、唤醒后读回，设置页因此可以跳过清黄。（`b03b645`）

## 设置、电池、音量与 NFC

音量 0 视为静音。只有超出 0–100 的值才会被修正。（`16c6ec2`）

设置增加 0–100 音量滑条，调节直接在当前页完成。设置行改用固定索引，列表变长时轮播和天气行仍然对齐。（`4d2c3d9`）

按住上键或下键时，滑条会在面板刷新和提示音结束后再迈下一步。设置行带上天气、播报和局域网图标。（`0101705`）

设置里增加只读电量。状态栏电量图标竖着画，高度 16 像素。NFC 电源开关会写入配置，重启和深睡之后保持关闭。（`b9dc421`）

设置页电量保持竖向，状态栏电量改为横向。（`44ddb2f`）

电量在 15% 及以下时，状态栏图标仍用文字颜色。音量和电量都显示纯数字。（`417e08b`）

状态栏电量从图标底部按百分比向上填充，代替原先固定的三段。（`690ca58`）

电量读取失败时上报值是 0。这时把它当成未知：状态栏不显示电量图标，设置里显示「--」。打开设置页时，两处用同一次采样刷新。（`fb7ba4b`）

## 界面字体

界面中文、拉丁字母和数字改用文泉驿点阵宋体，字号为 12、14、16 像素，去掉体积很大的思源轮廓字表。（`6d3394f`）

## 配网与局域网

局域网页可以把主机名、静态 IPv4 和 IPv6 写进 NVS。STA 按保存的地址启动，可以跳过 DHCP。（`1d9d3be`）

AP+STA 配网时保留 STA 网卡，直到 `Stop()` 把两块网卡都拆掉。这样关联之后 DHCP 和 `GOT_IP` 才会发生，设备能拿到 IP。（`16f7ad6`）

相册、配网和工具页用同一套页面框架生成，仓库里不附带 LuCI 源码缓存。（`869fd08`）

凭据一旦保存，就由 `/submit` 退出配网。APSTA 切信道常常丢掉 `done.html` 随后发出的 `/exit`，重复的退出请求直接放过。（`edc675f`）

配网连接改到后台任务里做。提交页面先拿到 HTTP 响应，再轮询 `/provision_status`，切信道时提交返回的 JSON 会留在页面上。（`b3ff01b`）

去掉多余的图片转换算法之后，补回局域网页面的初始化。否则残留的 `syncAlgoRow()` 会在 `theme.js` 之前抛错，单项导航无法收成「概览 / 相册 / 设置」。（`a77e5ab`）

同一批接入里，局域网网页随天气、日历和空闲睡眠一起挂到板上。（`70b40ee`）
